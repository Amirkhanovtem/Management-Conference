# Air Astana — XVIII Management Conference 2026

A responsive conference website built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion and Lucide.

## Run locally

```bash
npm install
npm run dev
```

Edit event content in `data/event.ts`, `data/agenda.ts`, `data/speakers.ts`, and `data/siteConfig.ts`. Registration, venue, directions, contacts and activity links are editable placeholders. Set `siteConfig.draft` to `false` to remove the preview badge after review.

The 14:00–14:20 Kahoot / 14:15–15:15 Panel #2 overlap and tentative 15:15 Q&A are preserved from the source agenda.
